Feature 01

Digital Twin — AWS SSO Multi-Account

Login SSO dan pengecekan seluruh AWS Account secara otomatis

Commands
# 1. Configure SSO session aws configure sso # 2. Login to SSO aws sso login --profile security-audit # 3. List all accounts in Organization aws organizations list-accounts \ --query 'Accounts[].{Id:Id,Name:Name,Status:Status}' # 4. Iterate through accounts for account in $(aws organizations list-accounts \ --query 'Accounts[].Id' --output text); do echo "Checking account: $account" aws sts assume-role \ --role-arn "arn:aws:iam::${account}:role/SecurityAuditRole" \ --role-session-name "KiroAudit" done # Output: 50 accounts discovered

Feature 02

Security Hub CSPM — Bulk Finding Collection

Mengumpulkan 5000+ findings dengan pagination handling

Commands & Process
# 1. Get findings with pagination (max 100 per page) aws securityhub get-findings \ --filters '{"RecordState":[{"Value":"ACTIVE","Comparison":"EQUALS"}]}' \ --max-items 100 # 2. Use NextToken for pagination loop next_token="" all_findings="[]" while true; do response=$(aws securityhub get-findings \ --filters '{"ComplianceStatus":[{"Value":"FAILED","Comparison":"EQUALS"}]}' \ --max-items 100 \ ${next_token:+--starting-token "$next_token"}) findings=$(echo "$response" | jq '.Findings') all_findings=$(echo "$all_findings $findings" | jq -s 'add') next_token=$(echo "$response" | jq -r '.NextToken // empty') [[ -z "$next_token" ]] && break done # 3. Export to CSV echo "$all_findings" | jq -r '.[] | [.Title, .Severity.Label, .Compliance.Status, .ProductName] | @csv' > security_hub_findings.csv # Result: 5000 findings exported to CSV

Example Finding: [EC2.19] Security groups should not allow unrestricted access to ports with high risk

Feature 03

AWS WAF WebACL Customization Rules

Custom rules untuk kebutuhan bisnis tanpa mengorbankan keamanan

Commands
# 1. List WebACLs aws wafv2 list-web-acls --scope REGIONAL # 2. Get WebACL Rules aws wafv2 get-web-acl \ --name "production-waf" \ --scope REGIONAL \ --id "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx" # 3. Check sampled requests (blocked) aws wafv2 get-sampled-requests \ --web-acl-arn "arn:aws:wafv2:..." \ --rule-metric-name "AWS-AWSManagedRulesCommonRuleSet" \ --scope REGIONAL \ --time-window '{"StartTime":"2026-10-01","EndTime":"2026-10-16"}' # 4. Add exclusion rule for legitimate traffic aws wafv2 update-web-acl \ --name "production-waf" \ --scope REGIONAL \ --id "xxx" --lock-token "xxx" \ --rules '[...]' \ --default-action '{"Allow":{}}' # False positive resolved, business traffic allowed
